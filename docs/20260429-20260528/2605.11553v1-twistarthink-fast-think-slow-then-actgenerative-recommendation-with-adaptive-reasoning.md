## 摘要
基于语义ID（SID）的生成式推荐已成为一种有前景的范式，但现有方法对所有用户序列统一采用固定的推理策略，要么快速直接生成，要么缓慢的思维链推理。这种方法导致了一种权衡：快速推荐模型在困难样本上产生次优准确度，而总是调用慢速推理则导致高延迟并在简单场景上浪费计算。为解决此问题，我们提出了“快思考，慢思考，然后行动”框架，该框架学习为每个用户序列自适应地分配推理努力。我们的系统为LLM配备了三个互补工具：基于SID的快速检索器、轻量级候选排序器，以及在推荐前生成显式理由的慢速推理模型。关键的是，我们通过将物品间知识转化为自然语言解释，将协同常识注入慢速模型。一个通过监督预热和后续的智能体强化学习训练的规划器，动态决定调用哪个工具。在三个数据集上的实验表明，我们的方法优于强基线，实现了持续的准确度提升，同时与统一慢速推理相比降低了推理延迟。

## Abstract
Generative recommendation with Semantic IDs (SIDs) has emerged as a promising paradigm, yet existing methods apply a fixed inference strategy, either fast direct generation or slow chain-of-thought reasoning, uniformly across all user histories. This approach creates a trade-off: fast recommendation model produces suboptimal accuracy on hard samples, while always invoking slow reasoning incurs prohibitive latency and wastes computation on easy cases. To address this, we propose Think Fast, Think Slow, Then Act, a framework that learns to adaptively allocate reasoning effort per user sequence. Our system equips an LLM with three complementary tools: a fast SID-based retriever, a lightweight candidate ranker, and a slow reasoning model that generates explicit rationales before recommending. Crucially, we inject collaborative commonsense into the slow model by transforming item-to-item knowledge into natural language explanations. A planner, trained through supervised warm-up followed by agentic reinforcement learning, dynamically decides which tool to invoke. Experiments on three datasets demonstrate that our method outperforms strong baselines, achieving consistent accuracy gains while reducing inference latency compared to uniform slow reasoning.

### 2. 论文提出的方法论

本论文提出的 TwiSTAR 框架核心思想是为一个语义对齐的大语言模型配备三个专用工具，并训练一个智能体规划器来动态决策调用。

*   **核心思想**：
    *   **自适应推理分配**：系统不像传统方法那样固定推理模式，而是学习何时“快思考”、何时“慢思考”、何时使用中间策略（排序），以平衡准确性和延迟。
    *   **协作常识注入**：将物品共现等协同过滤信号转化为自然语言解释，赋予慢速推理模型真正的“领域知识”，而非仅仅让模型记忆SID模式。

*   **关键技术组件与流程**：
    1.  **语义ID（SID）与基座模型对齐 (`Malign`)**：
        *   **SID生成**：利用残差向量量化（如RQ-VAE）将物品的文本元数据（标题、类别等）编码为离散的SID码序列。
        *   **语义对齐**：将SID码与物品原文术配对，输入预训练LLM进行微调（仅优化SID码对应的嵌入层）。目标是将没有语言学意义的离散SID码**接地**到LLM的文本语义空间，使模型能理解SID背后的物品含义。
    2.  **三个专用工具**：
        *   **快速推荐模型 (`Mfast`)**：基座模型在对齐后被训练为序列推荐模型，直接根据用户历史SID序列，通过受限波束搜索高效检索 top-K 候选物品SID。这代表“快思考”。
        *   **排序模型 (`Mrank`)**：一个基于深度兴趣网络(DIN)的轻量级判别式模型。它接收`Mfast`检索出的较大候选集（如 top-50），通过用户历史与候选物品的交互特征进行精排，输出更精准的 top-K 列表。这作为快思考和慢思考之间的折中方案。
        *   **慢速推理模型 (`Mslow`)**：这是实现“慢思考”的关键，其构建分两步：
            *   1. **协作常识注入**：从用户历史行为中挖掘高置信度的**物品-物品(I2I)对**，使用一个教师LLM为每对生成自然语言解释（例如，“用户买了A为什么也容易买B？”）。用这些 `<i, j, 解释>` 三元组微调基座模型，使其内化协同规律。
            *   2. **难例推理激活**：只选择那些**快速模型无法命中的困难样本**（`Mfast`在 top-50 中未命中目标）作为训练数据，使用 **GRPO** 强化学习算法训练模型，使其在给出最终推荐前，先生成显式的、有逻辑的思维链(`<think>...</think>`)。
    3.  **智能体规划器 (`Magent`) 的两阶段训练**：
        *   **阶段一：监督预热**。根据`Mfast`在验证集上的表现，为每个用户序列打上伪标签（如：快速命中→路径1，快速检索到但未排名靠前→路径2，快速未命中→路径3）。利用这些标签，通过交叉熵损失训练规划器如何调用对应的工具函数（如 `fast_rec(k)`, `rank_candidates(m,n)`, `think_and_rec(j)`）。
        *   **阶段二：智能体强化学习**。冻结所有工具模型，设计综合奖励函数（公式7）：`R_total = NDCG@10 + η * 过程是否有效 - β * 延迟成本`。使用GRPO等算法优化规划器，使其能自主学习在奖励（准确性）和惩罚（延迟）之间取得最佳平衡的决策。

1.  **整体最优**：TwiSTAR 框架在所有三个数据集和所有指标上均优于包括OneRec-Think在内的所有基线模型，证明了自适应推理方法的优越性。
2.  **组件有效性**：快速检索、排序和慢速推理三个组件对最终性能都不可或缺。移除任何一个都会导致性能下降。

6.  **路由决策的合理性**：学习到的规划器决策与最优方案有**78.3%的一致性**，且在其调用慢思考的序列中，有**86.2%是快速模型无法命中的真正难例**，验证了路由策略的高度准确性。
