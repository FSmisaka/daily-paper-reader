## 摘要
生成式推荐将推荐重新表述为对离散语义标识符（ID）的下一个标记预测。一个基本但未被探索的设计选择是，现有方法对所有项目采用固定长度的分词，这隐含假设了无论项目特征如何，编码容量都是统一的。通过在四个数据集上的系统实验，我们发现了流行度-长度悖论：热门项目使用短ID实现最佳性能，而尾部项目则需要更长的编码来捕捉区分性语义。这揭示了一个关键的不匹配，即热门项目受益于丰富的协同信号，只需要最少的语义细节，而尾部项目由于交互数据稀疏，必须依赖细粒度的内容特征。为了解决这个问题，我们提出了VarLenRec，一个学习可变长度分词的框架。我们开发了流行度加权信息预算分配（PIBA），这是一个信息论框架，证明了最优ID长度应随流行度的负幂次缩放。直接实现可变长度分配面临两个技术挑战：标准欧几里得残差量化缺乏几何容量以支持多样化的代码长度而不失真，并且离散的长度决策是不可微分的。我们通过双曲残差量化来解决这些问题，它利用庞加莱球的指数体积增长来自然分层编码容量，以及一个软长度控制器，它通过由PIBA导出的先验正则化的连续层保留概率，实现可微的长度预测。大量实验表明，VarLenRec在推荐准确性和训练/推理效率方面实现了比最先进方法显著的改进，揭示了自适应编码容量在生成式推荐中的重要性。

## Abstract
Generative recommendation reformulates recommendation as next-token prediction over discrete semantic identifiers (IDs). A fundamental yet unexplored design choice is that existing methods employ fixed-length tokenization for all items, implicitly assuming uniform encoding capacity regardless of item characteristics. Through systematic experiments across four datasets, we discover the Popularity-Length Paradox: popular items achieve optimal performance with short IDs, while tail items require substantially longer codes to capture discriminative semantics. This reveals a critical mismatch where popular items benefit from abundant collaborative signals and require minimal semantic detail, whereas tail items must rely on fine-grained content features due to sparse interaction data.   To address this, we propose VarLenRec, a framework for learning variable-length tokenization. We develop Popularity-Weighted Information Budget Allocation (PIBA), an information-theoretic framework proving that optimal ID length should scale as a negative power of popularity. Directly implementing variable-length allocation faces two technical challenges: standard Euclidean residual quantization lacks geometric capacity to support diverse code lengths without distortion, and discrete length decisions are non-differentiable. We address these through Hyperbolic Residual Quantization, which leverages the exponential volume growth of the Poincaré ball to naturally stratify encoding capacity, and a Soft Length Controller, which enables differentiable length prediction via continuous layer retention probabilities regularized by PIBA-derived priors. Extensive experiments demonstrate that VarLenRec achieves significant improvements over state-of-the-art methods in recommendation accuracy and training/inference efficiency, revealing the importance of adaptive encoding capacity in generative recommendation.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- 生成式推荐（Generative Recommendation）将推荐任务建模为对物品语义ID（Semantic IDs）的自回归预测。现有方法**无差别地为所有物品分配固定长度的语义ID**，默认每个物品所需的编码容量相同。
- 然而，推荐系统存在长尾分布：头部物品交互频繁，协同信号丰富；尾部物品交互稀疏，必须依赖细粒度内容特征。
- 论文通过实证发现**流行度‑长度悖论（Popularity‑Length Paradox）**：头部物品用短ID即可达到最优性能，而尾部物品性能随ID变长而提升；统一的固定长度只是全局的次优折衷。
- 整体含义：**语义ID的长度应根据物品流行度自适应调整**——热门物品使用短码，长尾物品使用长码，从而更合理地分配编码容量。

### 2. 论文提出的方法论：核心思想、关键技术细节

核心思想：基于信息论推导出最优ID长度与流行度负幂次相关（PIBA），并利用双曲空间实现可变长残差量化（HARQ），配合软长度控制器进行可微优化。

#### （1）流行度加权信息预算分配 (PIBA)
- 将推荐需要的总信息预算 `I_req` 分为两部分：**协同信号提供的信息** `I_collab(p_i) = α log(1+θp_i)`（对数增长，反映协同信号的边际递减）和**语义ID提供的信息** `I_semantic(L_i) = γ Σ_{l=1}^{L_i} 1/l ≈ γ ln L_i`（谐波模型）。
- 令语义信息恰好填满剩余缺口，推导出最优长度 `L_i* = C · p_i^{-α/γ}`，即**最优长度与流行度的负幂次成正比**。
- 实际采用排序分位映射将连续长度离散化：`L_i = clip(round(1 + (K-1)(r_i/(N-1))^β), 1, K)`，其中 `r_i` 为流行度排名，`β` 对应理论幂指数。

#### （2）双曲自适应残差量化 (HARQ)
- **双曲嵌入空间**：使用庞加莱球模型，其体积指数增长（`V(r) ∼ e^{(d-1)√c r}`），天然适合层次化语义编码。热门物品聚集在原点附近（小半径、短码），长尾物品分布至边界（大半径、长码），形成自然分层。
- **组件**：
  - 双曲编码器：将物品特征映射到庞加莱球 `z_i^{(0)} = exp_0^c(MLP(x_i))`。
  - 双曲残差量化器：逐层在双曲距离下搜索最近码本向量 `e^{(l)}`，计算双曲残差 `r_i^{(l)} = (-e^{(l)}) ⊕_c r_i^{(l-1)}`。
  - **软长度控制器**：在每一层，将当前残差和所选码本向量投影到欧氏空间后拼接，经MLP和sigmoid输出层保留概率 `α_i^{(l)}`。通过前缀约束 `m_i^{(l)} = ∏_{j=1}^{l} α_i^{(j)}` 得到可微的累积掩码。训练时用连续掩码，推理时以阈值离散化。
  - 双曲解码器：用裁剪后的累积掩码对码向量进行加权累加，重建物品特征 `y_i`。
- **训练目标**：
  - `L_recon`：原始特征与重建特征的均方误差。
  - `L_quant`：双曲距离下的矢量量化损失（编码器‑码本约束）。
  - `L_cost`：惩罚总层使用量 `Σ m_i^{(l)}`。
  - `L_len`：将累积掩码与PIBA导出的离散目标掩码 `t_i^{(l)}=1[l ≤ L_hat(p_i)]` 的二元交叉熵，实现理论先验正则化。
  - 总损失：`L = L_recon + L_quant + λ_cost L_cost + λ_len L_len`。
- 优化：采用黎曼Adam，通过指数映射保持码本位于流形内。

#### （3）可变长ID的下游集成
- **碰撞解决**：引入一个**不相交的辅助码本 {M+1,...,2M}**，为发生碰撞的ID序列追加唯一标识，避免干扰语义码本。
- **防幻觉**：基于所有有效ID构建前缀树（Trie），推理时进行约束束搜索，只允许生成树中存在的延续。
- **消除长度偏差**：束搜索后，用几率比重新评分 `s(z) = max(0, log[(P(z|u)/(1-P(z|u))) * ((1-P(z))/P(z))])`，以均值频率 `P(z)` 作为校准，提升高条件概率但低边缘概率的长序列得分。
