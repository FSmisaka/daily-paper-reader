## 摘要
生成式推荐模型将推荐重构为序列生成任务，将物品表示为离散的语义ID，对称地用作输入和预测目标。我们识别出该设计中的关键双阶段信息瓶颈：（1）输入瓶颈，有损量化会损害细粒度语义，而流行度偏差使学习到的表示偏向热门物品；（2）输出瓶颈，不精确的离散目标限制了监督质量。为解决这些问题，我们提出AsymRec，一个解耦输入与输出表示的非对称连续-离散框架。具体而言，多专家语义投影（MSP）通过专家专用的投影将连续嵌入映射到Transformer的隐藏空间，保留语义丰富性并改善对低频物品的泛化。多面层次量化（MHQ）通过多视角和多层级量化结合语义正则化，构建高容量、结构化的离散目标，在保持细粒度区分的同时防止维度坍缩。大量实验表明，AsymRec以平均15.8%的性能提升始终优于最先进的生成式推荐模型。代码将开源。

## Abstract
Generative Recommendation (GenRec) models reformulate recommendation as a sequence generation task, representing items as discrete Semantic IDs used symmetrically as both inputs and prediction targets. We identify a critical dual-stage information bottleneck in this design: (1) the Input Bottleneck, where lossy quantization degrades fine-grained semantics, while popularity bias skews the learned representations toward frequent items, and (2) the Output Bottleneck, where imprecise discrete targets limit supervision quality. To address these issues, we propose AsymRec, an asymmetric continuous-discrete framework that decouples input and output representations. Specifically, Multi-expert Semantic Projection (MSP) maps continuous embeddings into the Transformer's hidden space via expert-specialized projections, preserving semantic richness and improving generalization to infrequent items. Multi-faceted Hierarchical Quantization (MHQ) constructs high-capacity, structured discrete targets through multi-view and multi-level quantization with semantic regularization, preventing dimensional collapse while retaining fine-grained distinctions. Extensive experiments demonstrate that AsymRec consistently outperforms state-of-the-art generative recommenders by an average of 15.8 %. The code will be released.

## 1. 论文的核心问题与整体含义
- **问题背景**：生成式推荐（GenRec）将推荐任务转化为序列生成问题，物品被编码为离散的语义ID，并**对称地**用作模型输入与预测目标。
- **核心瓶颈**：该设计存在**双重信息瓶颈**。
  - **输入瓶颈**：有损量化导致细粒度语义丢失，且查表嵌入对热门物品的过更新使表示偏向流行项，损害低频（冷）物品的泛化。
  - **输出瓶颈**：传统简单量化产生噪声大、碰撞多的离散目标，监督信号不精确；若改用连续目标训练，则会导致输出表示出现**维度坍缩**（有效秩显著下降）。
- **整体含义**：论文提出**非对称连续‑离散框架 AsymRec**，通过解耦输入与输出表示，在保留连续嵌入语义丰富性的同时，利用结构化离散目标提供高保真监督，从而突破上述瓶颈，实现更精细、更鲁棒的生成式推荐。

## 2. 论文提出的方法论
- **整体思路**：输入侧使用**连续映射**保留语义拓扑；输出侧采用**多面层次量化**构建高容量离散监督信号，整体为Transformer生成式架构。
- **核心组件一：多专家语义投影（MSP）**
  - 不再将输入物品的语义ID转换为查表嵌入，而是直接对原始连续嵌入 `x_i` 进行投影。
  - 采用**Mixture‑of‑Experts**机制：`E` 个2层MLP专家 `f_e` 和一个门控网络 `g`，动态加权组合：
    - `h_i = Σ_{e=1}^E α_{i,e} f_e(x_i)`,  `α_i = g(x_i)`.
  - 好处：保留原始嵌入空间的拓扑结构，提升对冷物品的泛化；不同专家捕捉互补的语义子空间。
- **核心组件二：多面层次量化（MHQ）**
  - 先用可学习线性投影 `W_P` 将嵌入 `x` 映射到潜在空间 `z̃`，并**正交化为M个不相交子空间** `z^{(m)}`。
  - 在每个子空间内进行**深度为L的残差量化（RQ）**，逐级逼近残差，并用**指数移动平均（EMA）** 更新码本以稳定离散优化。
  - 最终物品获得长度为 `M×L` 的结构化语义ID序列 `{i_{m,l}}`。
  - **训练损失**：包含重构损失 `L_rec`、**子空间能量平衡损失** `L_bal`（防止信息坍缩到少数子空间）、**投影矩阵正交正则项** `L_reg`。
  - 该量化模块单独训练，训练完成后固定语义ID供下游生成模型使用。
- **生成模型训练**：物品序列经MSP得连续表示 `h_i`，加位置编码后送入Transformer Decoder；最后通过 `M×L` 个并行的预测头（两层MLP）预测下一物品的完整语义ID序列，优化交叉熵损失 `L_CE`。推理时采用图约束解码保证生成有效ID。
